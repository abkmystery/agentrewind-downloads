# AgentRewind for Windows

[**Download AgentRewindSetup.exe**](https://github.com/abkmystery/agentrewind-downloads/releases/download/v0.2.0-preview/AgentRewindSetup.exe)

1. Open **AgentRewindSetup.exe** from your Downloads folder.
2. Follow the setup prompts and open **AgentRewind**.
3. Choose what you want to watch. Start with a test folder so you can try restoring a change.

This preview runs on 64-bit Windows. It is an unsigned installer, so Windows may show an unknown publisher warning.
